# CS-009-PS-118

## Court Case Listing and Adjournment Scheduling Engine

### Problem Statement
PS-118 – Court Case Listing and Adjournment Scheduling Engine.

### Technology Stack
- Python 3.10+
- SQLite
- CSV
- Pytest
- Git and GitHub

### Project Description
This project automates court case admission, limitation
checks, court fee calculations, bench allocation,
cause list generation, adjournment scheduling,
case stage progression and pendency reporting.

### Status
Development in progress.
